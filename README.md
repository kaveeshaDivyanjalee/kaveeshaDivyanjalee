### ⚽ Data Preprocessing Impact on Model Accuracy — FIFA 21 Statistical Study
<p>
  <img src="https://img.shields.io/badge/R-276DC3?style=flat-square&logo=r&logoColor=white" />
  <img src="https://img.shields.io/badge/caret-ML-blue?style=flat-square" />
  <img src="https://img.shields.io/badge/ggplot2-Visualization-ff69b4?style=flat-square" />
  <img src="https://img.shields.io/badge/R%C2%B2-0.986-success?style=flat-square" />
  <img src="https://img.shields.io/badge/p--value-2.57e--10-critical?style=flat-square" />
</p>

**Research question:** Does data preprocessing significantly improve model accuracy?
**Dataset:** FIFA 21 messy raw data — **18,979 players, 77 features**. **My role:** Predictive Analytics Lead.

| Layer | What we did | Key result |
|---|---|---|
| 📋 **Descriptive** | Found and visualized currency strings, mixed units, missing values, outliers | Cleaner distributions, stronger correlations |
| 🧪 **Inferential** | 10-fold CV + paired t-test on R² | t = 29.88, p = 2.57 × 10⁻¹⁰, Hedges g = 9.84 |
| 🤖 **Predictive** | Linear Regression, Decision Tree, Random Forest, Gradient Boosting | Best: **Random Forest R² = 0.986**, RMSE ↓ 30–43% |

> 💬 **Conclusion:** Preprocessing is not optional — it is foundational.

👉 [**View Repository**](https://github.com/kaveeshaDivyanjalee/TPSM_Project)
